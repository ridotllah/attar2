1. **Hello World** → Program pertama untuk menampilkan teks ke layar.
2. **Operator Aritmatika** → Digunakan untuk menghitung seperti tambah, kurang, kali, bagi, dan sisa bagi.
3. **Operator Augmented Assignment** → Untuk menyingkat penulisan operasi matematika pada variabel.
4. **Operator Logika** → Menghubungkan pernyataan logika dengan “dan”, “atau”, dan “tidak”.
5. **Operator Unary** → Operator yang hanya melibatkan satu nilai, seperti menambah satu atau membalik logika.
6. **Operator Pembanding** → Membandingkan dua nilai, hasilnya benar atau salah.
7. **Tipe Data Array** → Menyimpan banyak nilai sekaligus dalam satu variabel.
8. **Tipe Data Boolean** → Nilainya hanya dua: benar (true) atau salah (false).
9. **Tipe Data Number** → Berisi angka, bisa bulat atau desimal.
10. **Tipe Data Object** → Menyimpan data dalam bentuk pasangan nama dan nilai.
11. **Tipe Data String** → Berisi teks atau tulisan.
12. **Variable** → Wadah untuk menyimpan data yang bisa digunakan ulang.
13. **If Expression** → Untuk membuat keputusan berdasarkan suatu kondisi.
14. **Switch** → Untuk memilih satu tindakan dari beberapa kemungkinan kondisi.
15. **Perbedaan If dan Switch** →

    * *If* cocok untuk kondisi rumit atau perbandingan nilai.
    * *Switch* cocok untuk kondisi yang pasti atau pilihan tetap.
